# Aerodrome source inputs

These 32 DAY table PNGs are the inputs pinned by `_images_sha256` in
`data/airfield-navaids.json`. The original release is **Aerodrome Data and
Frequencies — 01 February 2026**, by **Dima Kozyrev (DimOn)**, distributed as
freeware with unlimited distribution. The author's original notes are in
[Readme.txt](Readme.txt).

See [source credits and regeneration instructions](../../docs/development/airfield-navaids-source.md).
The images are retained for contributors and do not ship in the npm package.
Unused map, NIGHT and extra pages are excluded from Git.
